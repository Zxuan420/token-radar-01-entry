Token launch radar: a program (`main.ts`, Node 22, standard library only) that reads a sealed DefiLlama protocol snapshot, ranks pre-token protocols by an implied value derived from their own figures (TVL, 7-day growth, age with no token), and writes a dashboard — board, per-protocol detail view with concrete farm steps, and filters — plus `board.json` and `dossier.json`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
